Faust Stepper see every wire's value, sample by sample

What you see: the block diagram of process, drawn like faust -svg. The small labels on the wires show each signal's value at the current sample n.

Recursion A ~ B: the outputs of A go back to the inputs of B through a z⁻¹ box: a one-sample delay. Its label shows the value that wire had at sample n − 1 (it is 0 at n = 0). Faust draws this delay as a tiny ⊓ sign at the same place.

Use it: → next sample, ← previous, Home back to n = 0, Space play/pause. Hover a wire to highlight it; click it to add a column to the table. Guess mode hides the values of the current sample: work them out by hand, then click a ? to check.

Supported Faust: _ ! : , <: :> ~ ' @ mem, arithmetic and comparison operators, partial application (+(1)), definitions with parameters, with { }, par/seq/sum/prod, button checkbox hslider vslider nentry hbargraph vbargraph, math functions, select2, ma.SR, ma.PI, ba.if. Values use 32-bit floats and ints like Faust's default.
